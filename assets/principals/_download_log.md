### A note on Wikimedia rate-limiting during this session

This session ran several rounds of parallel/automated downloading against Wikimedia Commons in a short window, which triggered Commons' anti-abuse HTTP 429 throttling repeatedly and, for a period, caused some already-good files to be transiently overwritten with tiny (~2KB) "Too many requests" error-page placeholders by retry attempts before a final cleanup pass caught and removed them. The folder state was re-verified multiple times (file-open + size checks) before this log was finalized, and every file currently present passed verification as a real, openable image. If a `portrait_N` file in any folder is ever found to be a ~2KB non-image file, it is a leftover from this rate-limiting and should simply be deleted (there is no corresponding good version expected to reappear on its own).

## Method notes

- All Wikimedia Commons downloads used `Special:FilePath/<filename>?width=1280` (thumbnail rendition) rather than requesting full original resolution, since Wikimedia's servers rate-limit (HTTP 429) repeated full-resolution download requests from automated clients much more aggressively than thumbnail requests.
- All files were verified with a Python/Pillow script confirming they open as valid images and are not HTML error pages, with a 10KB minimum size floor.
- No AI-generated or deepfake images were used — all photos are real photographs sourced from Wikimedia Commons, official team sites, or press sites as noted above.
